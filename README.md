# Puls Cen

Приложение для отслеживания цен на товары с различных маркетплейсов.

## Особенности

- Отслеживание цен на товары с Ozon, Wildberries и других маркетплейсов
- Синхронизация данных через GitHub с шифрованием
- Поддержка автоматической синхронизации
- Возможность ручного ввода цен

## Установка

1. Скачайте последнюю версию APK файла
2. Разрешите установку из неизвестных источников (если требуется)
3. Установите приложение

## О программе

Это приложение позволяет отслеживать изменения цен на товары с различных маркетплейсов. 
Все данные шифруются и хранятся в вашем GitHub-репозитории.

## Обновления

Приложение автоматически проверяет наличие обновлений. Если вы хотите установить новую версию:
1. Откройте приложение
2. Перейдите в раздел "Настройки"
3. Нажмите "Проверить обновления"
