# Пульс цен

Приложение для Android и сайт для отслеживания цен на товары. Вы добавляете ссылку
на товар — «Пульс цен» открывает страницу, находит название, цену, первое фото и
артикул (для Wildberries и Ozon), а затем ведёт историю изменения цены. История
синхронизируется с публичным GitHub-репозиторием **только в зашифрованном виде**.

- Сайт: <https://romanlyavin.github.io/puls-cen/>
- Репозиторий: <https://github.com/RomanLyavin/puls-cen>
- Приложение: <https://github.com/RomanLyavin/puls-cen/releases/latest>

## Возможности

- регистрация по email и паролю с демонстрационным кодом подтверждения
  (письмо не отправляется — код показывается на экране и действует 15 минут);
- личный кабинет: имя и аватар (фотография из галереи);
- добавление товара по ссылке: название, цена, первое фото, артикул;
- автоматическая проверка цены, ручное обновление и ежедневная проверка
  через WorkManager;
- история изменений цены с графиком;
- запасной ручной ввод цены, если магазин блокирует автоматические запросы;
- общий аккаунт с сайтом: те же email и пароль, те же товары;
- страница «О программе» с кнопками «Обновить» (проверка релиза на GitHub,
  скачивание APK и сверка подписи) и «Поддержать»;
- светлая и тёмная тема, оформление в красном и белом.

## Как это работает

1. Приложение выводит ключ из пароля: **PBKDF2-HMAC-SHA256, 210 000 итераций**.
2. Данные шифруются **AES-256-GCM** (128-битный тег) и складываются в
   JSON-конверт `PULS-CEN-1` с солью, IV и шифротекстом.
3. Конверт публикуется в репозитории по пути
   `data/u/<sha256(email)>/bundle.enc`. Email в пути не раскрывается.
4. Сайт скачивает тот же файл и расшифровывает его в браузере через WebCrypto.
5. Без пароля нельзя увидеть ни список товаров, ни историю цен, ни имя и аватар.

Пароль не отправляется на сервер и не восстанавливается: он и есть ключ
шифрования. Если пароль потерян, доступ к аккаунту восстановить нельзя.

## Стек

- Kotlin, Jetpack Compose, Material 3, Coil, OkHttp, WorkManager;
- minSdk 26, targetSdk 35, JDK 17, Gradle 8.9;
- сайт — статический HTML/CSS/JS без сборки и без токена записи.

## Сборка

```powershell
$env:JAVA_HOME = "E:\Ai\OpenCode_APK\.tools\jdk\jdk-17.0.21+9"
$env:ANDROID_HOME = "E:\Ai\OpenCode_APK\.tools\android-sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME

.\gradlew.bat :app:testDebugUnitTest --console=plain
.\gradlew.bat :app:lintRelease --console=plain
.\gradlew.bat :app:assembleRelease --console=plain
```

Для публикации изменений нужен fine-grained GitHub-токен с доступом к
репозиторию `puls-cen` и правом `Contents: Read and write`. Токен хранится в
`local.properties` (`github.token=...`) и маскируется в `BuildConfig`, чтобы
GitHub не отозвал его автоматическим сканированием секретов в APK. Технически
токен из APK извлекаем — это ограничение подхода; токен ограничен одним
репозиторием. Пользователь также может ввести собственный токен в приложении:
«Профиль → Синхронизация → Настройки GitHub-токена».

Подпись релиза: `keystore.properties` и `puls-cen-release.jks` (в репозиторий
не попадают).

## Разработка

- `app/src/main/java/com/pulscen/app/data` — шифрование, модели, GitHub-клиент,
  синхронизация, парсинг цен;
- `app/src/main/java/com/pulscen/app/ui` — Compose-экраны;
- `app/src/main/java/com/pulscen/app/update` — проверка обновлений и подписи APK;
- `app/src/test` — unit-тесты криптографии, парсеров, слияния и обновлений;
- `index.html`, `assets/` — сайт для GitHub Pages.
